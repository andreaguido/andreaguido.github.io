## Courses

**Data Science with Python**<br>
An in-depth introduction to data science: handling complex data structures and using data to test theory.<br>
Materials: [GitHub](https://github.com/andreaguido/datasciencewithpython) · Textbook: VanderPlas, *Python Data Science Handbook*

**Applied Information Analysis (Microeconometrics)**<br>
Advanced microeconometric techniques for individual-level data, with an emphasis on practical skills in R and real-world applications.<br>
Materials: [GitHub](https://github.com/andreaguido/microeconometrics) · Textbook: Wooldridge, *Introductory Econometrics*
